# KyberOS components

Everything is generated by `build/build.py` into `dist/` (mirrors `~/.local/share`) from
the tokens in `build/palette.py`. Hand-written packages live in `src/`.

| Piece | Source | Installs to | Notes |
|---|---|---|---|
| Colour schemes ×6 | `build/gen_colors.py` | `color-schemes/KyberOS<Crystal>.colors` | one per kyber crystal |
| Plasma style | `build/gen_plasma.py` + `svgframe.py` | `plasma/desktoptheme/KyberOS` | follows the crystal via `ColorScheme-*` classes; shadows, translucent (blur) variants, sliders, scrollbars, diamond radios, switch, tabs |
| Window decoration ×6 | `build/gen_aurorae.py` | `aurorae/themes/KyberOS-<Crystal>` | Aurorae can't follow colour schemes, hence 6 variants |

| Static wallpapers ×6 | `build/gen_wallpaper.py` | `wallpapers/KyberOS-<Crystal>` | 4K, also the animated plugin's base art |
| Animated wallpaper | `src/plasma/wallpapers/org.kyberos.tactical` | `plasma/wallpapers/` | four responsive QML scenes (Tactical, Schematic, Targeting, Comms); `Scene=auto` picks per monitor: landscape → Tactical, portrait left of centre → Targeting, right → Comms; override per monitor in wallpaper settings. | New-monitor watcher | `kyberos-screens` + `system/kyberos-screens.service` | `~/.local/bin`, user unit | Plasma gives new screens the stock image plugin; this switches them to the animated one (leaves custom wallpapers alone) |

## Panel layout (`--layout`)
- **Top strip**: start (kyber crystal), pager, centred 24h clock (Michroma), diagnostics, tray.
  The tray sits between flexible spacers, so it widens as apps add icons.
- **Floating dock**: icon task manager + trash. `lengthMode=fit` grows it with every
  launcher/task; icons only shrink once it reaches the screen width. Always visible.

## Plasma 6.7 gotchas found while building
- Lock screen QML belongs to the shell package now, not the global theme; KyberOS themes it
  through the Plasma style + the lock-screen wallpaper plugin (`kscreenlockerrc [Greeter]`).
- Plasma Login Manager reads `[Greeter] WallpaperPluginId` (Fedora's defaults file uses a
  stale `WallpaperPlugin` key that is ignored).
- KWin disables all animations on software GL (llvmpipe) unless
  `KWIN_EFFECTS_FORCE_ANIMATIONS=1` (only needed in the virtio-gpu test VM).
- KWin shader effects: write core GLSL (`in`/`out`, `texture()`); KWin prepends `#version`.
  Uniforms are applied right before each window draws, so per-window values work via
  `Effect.ShaderUniform` animations with constant from/to.
- Plymouth 24: `Math.Random()` is constant and `Image.Rotate()` returns empty images, so the
  script uses its own PRNG and pre-rotated streak PNGs. Variables first assigned inside a
  function are local unless written through `global.`.
- `console=ttyS0` on the kernel command line forces Plymouth into text mode.
- Animators (XAnimator/ScaleAnimator...) fix from/to when they start: base sizes on `Screen`, not a
  window that may still be growing (the splash bunched up in a 150 px ball until this was fixed).
- QML gotchas hit here: a property named `data` (Item default property), upper-case method names,
  and `parent` inside a `ShapePath` (it is not the Shape) all break silently or at load. Run
  `qmllint` (`/usr/lib64/qt6/bin` on Fedora, `/usr/lib/qt6/bin` on Arch/Debian) before restarting plasmashell.
- Testing multi-monitor in the VM: `krfb-virtualmonitor --name Portrait --resolution 1080x1920`
  adds a real KWin output; capture all screens with `spectacle -b -n -f -o file` (via systemd-run).
- **Scenes can be built at size 0** (the multi-monitor login greeter does this). Any loop that runs "until it fills the width" never ends, eating memory until the OOM killer steps in. `Readout.qml` did this and took a three-monitor greeter to 59 GB. Every size-derived loop or count needs a guard and a cap; `main.qml` also holds the scene Loader until it has a size.
- **Restarting `plasmalogin` straight away races** with the old greeter's compositor shutting down ("transaction is destructive"), leaving no greeter on screen. Use `systemctl stop plasmalogin; sleep 4; systemctl start plasmalogin`.
- **A running KWin won't load newly installed effects**, even on reconfigure. Call `org.kde.kwin.Effects.loadEffect`.
